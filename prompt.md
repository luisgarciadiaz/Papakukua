Actúa como un desarrollador senior experto en desarrollo web full-stack. Quiero crear el MVP de "Pápakukua", una aplicación web minimalista y moderna para el seguimiento de hábitos diarios (habit tracker).

### Requisitos técnicos y de diseño:
1. **Stack:** Stack moderno y ligero (ej. HTML5, Tailwind CSS y JavaScript vainilla con almacenamiento en localStorage, o un componente modular limpio si usas un framework ligero).
2. **Interfaz (UI/UX):** 
   - Diseño limpio, minimalista y responsivo (optimizado para móvil y escritorio).
   - Modo oscuro/claro nativo o estético.
   - Panel principal con la lista de hábitos del día actual y sus estados (completado/pendiente).
3. **Funcionalidades Core:**
   - **CRUD de hábitos:** Poder agregar un nuevo hábito (con nombre y categoría) y eliminarlo.
   - **Check diario:** Marcar/desmarcar los hábitos completados para el día de hoy.
   - **Rachas (Streaks):** Calcular y mostrar la racha actual de días consecutivos cumplidos para cada hábito.
   - **Persistencia:** Guardar los datos en el `localStorage` del navegador para que no se pierdan al recargar.
